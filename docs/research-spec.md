# FAHIMTA Research Specification

## Purpose

FAHIMTA (Hausa–Nigerian AI Evaluation & Improvement Framework) is a research and engineering framework for evaluating, diagnosing, and supporting improvement of Hausa/Nigerian-language AI systems.

The initial target system is N-ATLAS.

FAHIMTA complements N-ATLAS. It does not replace, rebuild, or claim ownership of N-ATLAS functionality.

## Research loop

**Evaluate → Diagnose → Improve → Re-evaluate**

The MVP demonstrates one reproducible evaluation path rather than a broad platform.

## Initial evaluation dimensions

Potential dimensions include Hausa-language understanding, semantic/meaning preservation, Nigerian cultural/contextual relevance, correctness, instruction following, consistency, and error classification.

The MVP must implement only dimensions for which a scoring rule and evaluation procedure are explicitly documented.

## Evidence discipline

FAHIMTA must not invent benchmark results, statistical significance, superiority claims, or production-readiness claims.

Current status: research prototype / MVP scaffold.
